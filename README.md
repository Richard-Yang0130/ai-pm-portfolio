# AI PM Portfolio

个人 AI 产品经理求职作品集网站，面向 GitHub Pages 部署。

## 本地开发

```bash
npm install
npm run dev
```

## 验证

```bash
npm test
npm run build
```

## 部署

项目页地址：

```text
https://Richard-Yang0130.github.io/ai-pm-portfolio/
```

Vite 已配置 `base: '/ai-pm-portfolio/'`。当前使用 `gh-pages` 分支发布 `dist`，不依赖 GitHub Actions workflow 权限。
