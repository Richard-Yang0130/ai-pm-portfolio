# 当前首屏方向

用户修正：不要头像，不要原站人物或他人内容；使用参考站的交互思路，视觉元素重新创作。此要求覆盖本次早先的一比一复刻规格。

- 暖纸色、薄荷与淡紫光晕，CSS 壁纸。
- 3 张内置 imagegen 原创透明 PNG：laptop.png、chip.png、evaluation-lens.png；完整提示词与来源见 public/desktop/original/manifest.json。
- CSS 健康球、纸稿、PRD 便笺和项目夹。分别对应简历中的 Aevis、文章、产品设计和六项项目。
- 纯 CSS/lucide Dock 和播放器。没有原站图片、个人照片、人物、动物或影视角色。
- Desktop({onOpen,onNavigate,music}) 回调契约保留；拖动和点击区分、键盘移动、resize 重置、小屏幕边界保留。
- 主 App 的介绍、来信和个人窗口使用文字/品牌图形，作品图库只含内容成果和本站原创插画。
- 项目按简历六项，不额外增加其他人的履历或项目。
